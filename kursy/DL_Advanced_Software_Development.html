Курс не структурирован по силлабусу: тематические разделы отсутствуют, все материалы и разнородные задания находятся в общем разделе GENERAL. Текущие задания не соответствуют силлабусу по программированию; необходимо создать 16 разделов тем и добавить 3 задания с экзаменом согласно силлабусу.
